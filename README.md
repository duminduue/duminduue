## 🦾 Engineering Project Journey

My project journey focuses on applying engineering principles to practical systems and progressively integrating intelligent technologies.

### ⚙️ Self-Balancing Mobile Robot

<sub>Robotics · ESP32 · MPU6050 · PID Control · Encoder Feedback</sub>

A two-wheel self-balancing mobile platform developed to explore feedback control, inertial sensing, and embedded motor control.

- ⚙️ PID-based balancing and controller tuning
- 📐 Mechanical chassis design
- 🔌 ESP32 and MPU6050 integration
- 🛞 Motor control and encoder feedback
- 🧪 Stability and disturbance-recovery testing

### ❤️ IoT-Based Health Monitoring System

<sub>Embedded Systems · ESP32 · MAX30102 · DS18B20 · DHT11 · Blynk</sub>

An IoT monitoring system integrating physiological and environmental sensors with a microcontroller-based interface.

- 💓 Heart-rate and SpO₂ monitoring
- 🌡️ Temperature and humidity sensing
- 📟 Display integration
- 📡 Wireless monitoring using Blynk IoT
- 🔧 Sensor integration and system testing

*Further documentation and public repository links can be added as they become available.*
