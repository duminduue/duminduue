## 🦾 Engineering Experience & Project Journey

My engineering journey focuses on applying mechanical, electronic, and software concepts to practical systems. The following projects represent key areas of my hands-on development.

### 01 · Self-Balancing Mobile Robot

**Focus:** Robotics · Embedded Systems · Feedback Control

A two-wheel self-balancing mobile platform developed around inertial sensing and PID-based balance control.

- ⚙️ Implemented PID-based balancing and controller tuning.
- 📐 Designed the mechanical chassis using CAD tools.
- 🔌 Integrated an ESP32 microcontroller and MPU6050 inertial measurement unit.
- 🛞 Worked with motor control and encoder-based feedback.
- 🧪 Explored stability, disturbance recovery, and movement performance.

### 02 · IoT-Based Health Monitoring System

**Focus:** Embedded Systems · Sensors · Internet of Things

An IoT monitoring project integrating physiological and environmental sensors with a microcontroller-based monitoring interface.

- 💓 Heart-rate and SpO₂ monitoring using MAX30102.
- 🌡️ Temperature and humidity monitoring using suitable sensors.
- 📟 Display integration for local readings.
- 📡 Wireless monitoring using Blynk IoT.
- 🔧 Practical sensor integration, wiring, and system testing.

*These projects demonstrate areas of practical engineering experience. Further project documentation and public code links can be added as they become available.*
